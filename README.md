# 保存呼出し工房 使用手引書

[保存呼出し工房の使い方を読む](https://creativeandcreative9.github.io/GP25_manual/)

Unityで作業状態を保存し、呼び出す手順と、呼び出す前に戻す方法を説明しています。
同じ素材を使うほかのシーンへの影響や、保存できないものも確認できます。

本文は `index.html`、画像は `images/` にあります。フォルダーを保ったままHTMLを開けば、手元でも読めます。
パソコン・スマートフォンの幅と印刷に対応し、外部フォントやJavaScriptは使いません。

著作権は、作者（アプリ工房ルナ）が持ちます。
